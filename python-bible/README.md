# Python Bible

## 10-project mastery path

Each project is a real build. Learn the required Python concepts, implement them, test them, debug them, refactor them, and document the final result.

1. **Personal Finance CLI** — fundamentals, functions, collections, files, JSON/CSV, exceptions, CLI.
2. **Smart File Automation System** — pathlib, filesystem automation, regex, hashing, logging, argparse.
3. **WFM Data Analyzer** — pandas, NumPy, datetime, validation, aggregation, reporting and charts.
4. **WFM REST API + Database** — FastAPI, Pydantic, SQLAlchemy, SQL, SQLite/PostgreSQL, REST.
5. **Production Web Data Pipeline** — HTTP, APIs, parsing, pagination, retries, timeouts, persistence.
6. **Automation Job Platform** — OOP, packages, decorators, context managers, queues, scheduling, architecture.
7. **Concurrent Processing Engine** — asyncio, threading, multiprocessing, futures, queues, cancellation and performance.
8. **Data Engineering Pipeline** — ETL/ELT, SQL, Parquet, DuckDB/PostgreSQL, data quality, idempotency.
9. **AI/RAG Knowledge Assistant** — document ingestion, chunking, embeddings, retrieval, vector search, LLM APIs and evaluation.
10. **RTA Command Center** — final capstone combining Python, data, APIs, databases, testing, concurrency, architecture, security and deployment.

## Coverage map

Python syntax → data model → control flow → functions → modules/packages → exceptions → files → CLI → OOP → typing → dataclasses → iterators/generators → decorators → context managers → regex → logging → testing/pytest → HTTP/API clients → pandas/NumPy → SQL/databases → FastAPI/Pydantic → async/concurrency → ETL → packaging → configuration → security → Docker → CI/CD → production architecture.

## Project rule

No filler projects. Small exercises are allowed inside a project, but these ten are the only major projects. Project 10 is the final integration test of the entire Bible.
