# Changelog

## Execution Foundation 0.2 — 2026-08-29

- Added FastAPI internal execution API.
- Added strict CPython 3.14.6 runtime verification.
- Added project and file workspace operations.
- Added path traversal protection.
- Added BUILD using `py_compile`.
- Added RUN runtime gate.
- Added EXECUTE with stdout/stderr and exit code capture.
- Added execution timeout handling.
- Added browser execution interface.
- Added Docker runtime definition for CPython 3.14.6.
- Added foundation tests.

## Foundation 0.1 — 2026-08-29

- Initialized the WebPython project specification.
- Defined the foundation architecture.
- Locked CPython 3.14.6 as the target runtime.
- Defined BUILD → RUN → EXECUTE as the core lifecycle.
- Added acceptance tests and architecture decisions.
