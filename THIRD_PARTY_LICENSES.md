Official licensing information:

## Python packages

Every Python package added as a runtime dependency must have its license reviewed and recorded here or in an automatically generated dependency notice before a production release.

## Frontend packages

Every JavaScript/CSS package added to the frontend must have its license reviewed and recorded here or in an automatically generated dependency notice before a production release.

## Important boundary

The MIT license in `LICENSE` applies to **WebPython project code authored for this repository**. It does not override the licenses of CPython or third-party dependencies.
